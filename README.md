## Directory Structure

* **`core` directory:**
  Shared configuration across all hosts is stored here. NixOS and Home Manager modules in this directory are automatically loaded for every host.

* **`desktop` directory:**
  Host-specific configuration for the `nix-desktop` machine. This includes its `configuration.nix`, `hardware-configuration.nix`, and hardware- or service-specific modules.

* **`laptop` directory:**
  Host-specific configuration for the `nix-laptop` machine. This includes its `configuration.nix`, `hardware-configuration.nix`, and laptop-specific modules.

* **`config` directories:**
  Application configuration files that are managed through Home Manager are stored alongside the relevant module.

The flake automatically discovers `.nix` files inside `core`, `desktop`, and `laptop`, so new modules can be added without manually importing them into `flake.nix`.

## How to Set Up a Machine

1. Install NixOS on the machine.

2. Enable flakes by adding the following to `/etc/nixos/configuration.nix`:

   ```nix
   nix = {
     extraOptions = ''
       experimental-features = nix-command flakes
     '';
   };
   ```

3. Apply the initial NixOS configuration:

   ```bash
   sudo nixos-rebuild switch
   ```

4. Enter a temporary shell containing Git:

   ```bash
   nix-shell -p git
   ```

5. Clone this repository:

   ```bash
   git clone https://github.com/MichaelAug/NixOS-Config.git
   cd NixOS-Config
   ```

6. Change the `username` variable in `flake.nix` to the username you want to use:

   ```nix
   username = "michael";
   ```

   Also update `nixos_config_dir` if the repository is located somewhere other than the default path.

7. Choose the appropriate host configuration:

   * For a desktop, modify `desktop/` as necessary.
   * For a laptop, modify `laptop/` as necessary.

   In particular, review the hardware-specific modules and remove or replace any driver configuration that does not apply to your machine.

8. Copy the hardware configuration generated by the NixOS installer into the appropriate host directory. For example, for `nix-desktop`:

   ```bash
   sudo cp /etc/nixos/hardware-configuration.nix ./desktop/
   ```

   For a laptop:

   ```bash
   sudo cp /etc/nixos/hardware-configuration.nix ./laptop/
   ```

9. Update the flake inputs:

   ```bash
   nix flake update
   ```

10. Apply the configuration for the appropriate host:

```bash
sudo nixos-rebuild switch --flake .#nix-desktop
```

Or:

```bash
sudo nixos-rebuild switch --flake .#nix-laptop
```

11. If the new configuration works correctly, the old non-flake configuration in `/etc/nixos/` can be removed:

```bash
sudo rm -rf /etc/nixos/
```

## After Setup

Update flake inputs:

```bash
update
```

Switch to the current configuration:

```bash
switch
```

## Git Hooks

After cloning the repository, enable the included Git hooks:

```bash
git config core.hooksPath .githooks
```
